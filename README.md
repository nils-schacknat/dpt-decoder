## DPT Decoder Implementation
This repository implements a [Dense Prediction Transformer](https://arxiv.org/abs/2103.13413) (DPT) decoder that can be used on top of frozen [DINOv2](https://arxiv.org/abs/2304.07193) features.

Using this setup I score an mIoU of 0.82 on the [GOOSE 2D Semantic Segmentation Challenge](https://www.codabench.org/competitions/5743/).
